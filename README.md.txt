# HelpDesk

Sistema web para gerenciamento de chamados de suporte de TI.

## Objetivo

O projeto tem como objetivo permitir que usuários abram solicitações de suporte e acompanhem seus chamados, enquanto técnicos podem gerenciar, atender e registrar a resolução das solicitações.

## Tecnologias

- React
- JavaScript
- Node.js
- Express
- PostgreSQL
